# Warp → Clash 临时订阅生成器

利用 Cloudflare Warp MASQUE 协议一键生成 Clash 临时订阅链接。

## 使用方法

见 [使用教程](./使用Cloudflare%20Warp生成MASQUE临时Clash订阅.md)。

```powershell
.\ConvertTo-WarpClash.ps1
# 或双击 生成订阅.bat
```
